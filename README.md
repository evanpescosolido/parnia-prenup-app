# Prenup Planner

Prototype web app for prenup and postnup readiness planning. The app is educational and issue-spotting oriented. It does not draft legal agreements or replace attorney review.

## Current v1 Scope

- Guided prenup/postnup intake
- Timing and process-readiness questions
- Current asset and future asset prompts
- International asset issue spotting
- Static state-law context for Massachusetts, California, and New York
- In-browser report generation with no login, database, or stored personal answers

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

State-law content is a prototype knowledge layer and should be reviewed by a qualified legal researcher before public use.
